# Qdrant Console Queries

Practice queries for the Qdrant Web UI Console.

Open: `http://localhost:6333/dashboard` → **Console**

Default collection name in this project: `documents`  
(`QDRANT_COLLECTION_NAME`)

Copy one block at a time and click **RUN**.

---

```http
# 1. List all collections
GET collections

# 2. Collection info (vectors config, point count, payload indexes)
GET collections/documents

# 3. Browse first 10 points (payload only, no embeddings)
POST collections/documents/points/scroll
{
  "limit": 10,
  "with_payload": true,
  "with_vector": false
}

# 4. One point including its embedding vector
POST collections/documents/points/scroll
{
  "limit": 1,
  "with_payload": true,
  "with_vector": true
}

# 5. Only chunks from one file (uses the filename payload index)
POST collections/documents/points/scroll
{
  "limit": 20,
  "with_payload": true,
  "with_vector": false,
  "filter": {
    "must": [
      {
        "key": "filename",
        "match": { "value": "sample.pdf" }
      }
    ]
  }
}

# 6. Count all points in the collection
POST collections/documents/points/count
{
  "exact": true
}

# 7. Count points for one filename
POST collections/documents/points/count
{
  "exact": true,
  "filter": {
    "must": [
      {
        "key": "filename",
        "match": { "value": "sample.pdf" }
      }
    ]
  }
}

# 8. Inspect collection again (check payload_schema.filename for the index)
GET collections/documents

# 9. Delete all points for one file (destructive)
POST collections/documents/points/delete
{
  "filter": {
    "must": [
      {
        "key": "filename",
        "match": { "value": "sample.pdf" }
      }
    ]
  }
}

# 10. Delete the whole collection (nuclear; app recreates it on next ingest)
DELETE collections/documents
```
